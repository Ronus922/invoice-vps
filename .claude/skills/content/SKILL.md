## **Hebrew Writing Rules**

### **Numbers**

| Context | Rule | Example |
|---------|------|---------|
| 1-10 | כתוב במילים | שלושה לקוחות, חמישה ימים |
| 11+ | כתוב בספרות | 15 לקוחות, 200 משתמשים |
| אחוזים | ספרות + סימן | 25%, לא עשרים וחמישה אחוז |
| כסף | ספרות + ₪ | 150 ₪, לא מאה וחמישים שקלים |
| טלפון | עם מקף | 050-123-4567 |
| תאריכים | DD/MM/YYYY | 15/01/2026 |

### **Punctuation**

```
✅ נקודה בסוף משפט.
✅ פסיק לפני "אבל", "אך", "אולם"
✅ נקודותיים לפני רשימה או ציטוט:
✅ מרכאות כפולות לציטוט: "טקסט"
✅ מרכאות בודדות למונח: 'API'

❌ אין רווח לפני סימן פיסוק
❌ אין נקודה אחרי כותרת
❌ אין שלוש נקודות (...) - השתמש בתו מיוחד: …
```

### **Abbreviations**

| סוג | כלל | דוגמה |
|-----|-----|-------|
| ראשי תיבות | עם גרש | צה"ל, ת"א |
| קיצורים | עם נקודה | וכו'. ד"ר. פרופ'. |
| מספרים סידוריים | עם גרשיים | ה-15, ה-3 |

### **Gender & Plurality**

```
✅ פנייה ניטרלית כשאפשר: "הזינו את הפרטים" (לא "הזן/הזיני")
✅ אם חייבים - לכו"נ: "הזן/י את הפרטים"
✅ ברבים - זכר: "המשתמשים יכולים" (לא "המשתמשות יכולות")
```

## **Tone & Voice**

### **Default Tone: Professional-Friendly**

```
✅ מקצועי אך נגיש
✅ ברור וישיר
✅ מכבד את הזמן של הקורא
✅ פעיל, לא סביל

❌ לא פורמלי מדי ("הנני להודיעכם")
❌ לא קז'ואלי מדי ("היי מה קורה")
❌ לא מתנשא
❌ לא מסורבל
```

### **Voice Examples**

| ❌ לא ככה | ✅ ככה |
|----------|--------|
| הנכם מוזמנים למלא את הטופס | מלאו את הטופס |
| במידה ותרצו לקבל מידע נוסף | רוצים לדעת עוד? |
| יש באפשרותכם ליצור קשר | צרו קשר |
| השירות שלנו מאפשר לכם | עם השירות שלנו תוכלו |

### **Formality Scale**

```
1. Formal:      "נשמח לעמוד לרשותכם"
2. Professional: "נשמח לעזור" ← DEFAULT
3. Friendly:    "נשמח לעזור לך!"
4. Casual:      "מה קורה? צריך עזרה?"
```

## **Landing Page Structure**

### **Hero Section**

```
[כותרת ראשית - 5-8 מילים, תועלת ברורה]
[תת-כותרת - 15-20 מילים, הרחבה]
[CTA ראשי] [CTA משני - אופציונלי]
```

**Formula:** מה + למי + תוצאה

```
❌ "פתרון תוכנה מתקדם לניהול עסקים"
✅ "נהלו את העסק מהטלפון - בלי כאב ראש"
```

### **Benefits Section**

```
3-4 יתרונות מרכזיים
כל יתרון:
  - אייקון
  - כותרת (3-5 מילים)
  - הסבר (10-15 מילים)
```

**Formula:** פיצ'ר → תועלת

```
❌ "מערכת מבוססת ענן"
✅ "גישה מכל מקום - עבדו מהבית, מהמשרד, או מהים"
```

### **Social Proof Section**

```
- לוגואים של לקוחות (5-8)
- ציטוט + שם + תפקיד + תמונה
- מספרים: "500+ עסקים", "98% שביעות רצון"
```

### **FAQ Section**

```
5-7 שאלות נפוצות
מבנה:
  שאלה: קצרה, ברורה (5-10 מילים)
  תשובה: ישירה, 2-3 משפטים
```

## **Email Templates**

### **Structure**

```
Subject: [מספר/emoji אופציונלי] + תועלת ברורה (< 50 תווים)
Preview: משפט פתיחה מסקרן (< 90 תווים)

---

שלום [שם],

[פסקה 1: הקשר/בעיה - 2-3 משפטים]

[פסקה 2: פתרון/הצעה - 2-3 משפטים]

[CTA ברור]

בברכה,
[שם]
[תפקיד]
```

### **Subject Line Formulas**

```
✅ שאלה: "מתכננים שדרוג? יש לנו הצעה"
✅ מספר: "3 דרכים לחסוך 50% בעלויות"
✅ דחיפות עדינה: "ההצעה מסתיימת ביום שלישי"
✅ אישי: "[שם], הכנו לך משהו"

❌ CAPS LOCK או סימני קריאה מרובים!!!
❌ "אל תפספסו!!!" - ספאמי
❌ כותרות ארוכות שנחתכות
```

### **Email Types**

| Type | Tone | Length |
|------|------|--------|
| Welcome | חם, מזמין | קצר - 3-4 משפטים |
| Newsletter | מקצועי, ערכי | בינוני - 5-7 משפטים |
| Transactional | ישיר, ברור | קצר מאוד - 2-3 משפטים |
| Sales | משכנע, לא לוחץ | בינוני - עם bullets |
| Support | אמפתי, פרקטי | לפי הצורך |

## **UI Microcopy**

### **Form Labels**

```
✅ קצר: "שם מלא", "טלפון", "אימייל"
❌ ארוך: "אנא הזינו את שמכם המלא"

✅ Placeholder כהסבר: "050-123-4567"
❌ Placeholder כ-label (נעלם בהקלדה)
```

### **Buttons**

```
✅ פועל + (מושא): "שלחו פנייה", "הורידו עכשיו"
❌ כללי מדי: "לחצו כאן", "שליחה"

✅ ספציפי: "קבלו הצעת מחיר"
❌ עמום: "המשך"
```

### **Error Messages**

```
מבנה: [מה קרה] + [מה לעשות]

✅ "מספר הטלפון לא תקין. הזינו 10 ספרות"
❌ "Error: Invalid phone format"

✅ "הסיסמה חייבת לכלול לפחות 8 תווים"
❌ "סיסמה לא תקינה"
```

### **Success Messages**

```
✅ "הפנייה נשלחה! נחזור אליכם תוך יום עסקים"
✅ "הסיסמה עודכנה בהצלחה"

❌ "Success"
❌ "הפעולה בוצעה" (איזו פעולה?)
```

### **Empty States**

```
✅ "עדיין אין הודעות. כשתקבלו הודעה, היא תופיע כאן"
✅ "אין תוצאות לחיפוש. נסו מילות חיפוש אחרות"

❌ "No data"
❌ "אין פריטים"
```

### **Loading States**

```
✅ "טוען..." / "שולח..." / "מעבד..."
✅ Skeleton loaders (לא רק spinner)

❌ רק spinner ללא טקסט
❌ "Loading..."
```

## **CTAs (Call to Action)**

### **Primary CTA Rules**

```
1. פועל ציווי: "קבלו", "התחילו", "הורידו"
2. תועלת ברורה: "קבלו הצעה חינמית"
3. 2-4 מילים
4. בולט ויזואלית
```

### **CTA Bank**

| Intent | Hebrew CTA |
|--------|------------|
| Sign up | הרשמו עכשיו / התחילו בחינם |
| Contact | צרו קשר / שלחו פנייה / דברו איתנו |
| Learn more | גלו עוד / קראו עוד / למידע נוסף |
| Download | הורידו עכשיו / קבלו את המדריך |
| Buy | לרכישה / הזמינו עכשיו |
| Quote | קבלו הצעת מחיר / לקבלת הצעה |
| Demo | תאמו הדגמה / צפו בהדגמה |
| Try | נסו בחינם / התנסו עכשיו |

### **Urgency (Use Sparingly)**

```
✅ "ההצעה בתוקף עד 31/01"
✅ "נותרו 3 מקומות אחרונים"

❌ "מהרו!!!" - ספאמי
❌ "הזדמנות אחרונה" (כשזה לא נכון)
```

## **SEO Guidelines**

### **Title Tag**

```
Format: [Keyword] - [Benefit] | [Brand]
Length: 50-60 תווים

✅ "ייעוץ פנסיוני - חסכו אלפי שקלים | מטרות פיננסי"
❌ "מטרות פיננסי - ייעוץ פנסיוני וביטוח ותכנון פרישה ועוד"
```

### **Meta Description**

```
Length: 150-160 תווים
Include: keyword + תועלת + CTA

✅ "ייעוץ פנסיוני מקצועי שיחסוך לכם עד 30% בדמי ניהול. 
    קבלו בדיקת פנסיה חינמית ←"
```

### **H1**

```
- אחד בעמוד בלבד
- מכיל את ה-keyword הראשי
- קורא לפעולה או מבטיח תועלת
```

### **H2-H6**

```
- מבנה היררכי (H2 אחרי H1, H3 אחרי H2)
- כל H2 = נושא משנה
- כוללים keywords משניים
```

### **Image Alt Text**

```
✅ תיאורי: "גרף המציג חיסכון של 30% בדמי ניהול פנסיה"
✅ קצר: "לוגו מטרות פיננסי"

❌ "image1.jpg"
❌ קיצורים: "גרף חסכון פנסיה img"
❌ Keyword stuffing
```

## **Common Mistakes**

### **Hebrew Mistakes**

| ❌ שגוי | ✅ נכון |
|--------|---------|
| באימייל | במייל / בדוא"ל |
| אפליקציה | אפליקציה / יישומון |
| פידבק | משוב |
| סטטוס | מצב |
| איוונט | אירוע |
| קונטנט | תוכן |

### **Style Mistakes**

```
❌ משפטים ארוכים מדי (מעל 20 מילים)
❌ פסקאות ארוכות (מעל 4 שורות)
❌ שימוש יתר ב-Bold
❌ יותר מסימן קריאה אחד!
❌ שלוש נקודות... (השתמשו ב-…)
```

### **UX Writing Mistakes**

```
❌ הודעות שגיאה טכניות למשתמש
❌ כפתורים עמומים ("אישור", "ביטול")
❌ חוסר עקביות במינוח
❌ טקסט placeholder שנעלם
```

## **Checklist**

Before publishing any content:

- [ ] **Grammar**: בדיקת שגיאות כתיב ודקדוק
- [ ] **Tone**: מתאים לקהל היעד
- [ ] **Length**: משפטים קצרים, פסקאות קצרות
- [ ] **CTA**: ברור ומזמין לפעולה
- [ ] **Numbers**: לפי הכללים (מילים/ספרות)
- [ ] **Punctuation**: נכון ועקבי
- [ ] **SEO**: Title, Description, H1 מותאמים
- [ ] **Mobile**: קריא במסך קטן
